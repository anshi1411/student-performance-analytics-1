# Student Performance Analytics System

## Project Overview
The Student Performance Analytics System is a beginner-friendly Python project that analyzes student marks and attendance. It generates useful insights such as total marks, average marks, grades, pass/fail results, and top performers.

## Objectives
- Calculate total and average marks for students.
- Assign grades based on average marks.
- Identify passing and failing students.
- Analyze subject-wise performance.
- Find the top-performing students.
- Generate reports using CSV files.

## Technologies Used
- Python
- Pandas
- NumPy

## Project Structure
- `main.py` — Main Python program
- `data/students.csv` — Sample student dataset
- `docs/Project_Documentation.md` — Project documentation
- `outputs/student_results.csv` — Student performance report
- `outputs/subject_analysis.csv` — Subject-wise analysis
- `requirements.txt` — Required Python libraries

## How to Run the Project

1. Download or clone this repository.
2. Install the required libraries:

   `pip install -r requirements.txt`

3. Run the program:

   `python main.py`

## Analysis Performed
- Student-wise marks and grades
- Class average and highest/lowest scores
- Pass/fail analysis
- Attendance monitoring
- Subject-wise average marks
- Department-wise performance
- Top five performers

## Dataset
This project includes 20 fictional sample student records for demonstration purposes.

## Learning Outcomes
This project demonstrates Python functions, conditional statements, loops, NumPy operations, Pandas DataFrames, CSV file handling, and basic data analysis.
